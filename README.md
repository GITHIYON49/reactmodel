This project is created using React.js and Tailwind CSS.

Tailwind CSS is used for styling the components and enhancing the UI.

The React Toastify package is used to show pop-up notifications when a product is added to the cart.

If the product is already in the cart, a notification indicates that it is already added.

The Lucide Icons package is used to make the UI more attractive.

Application state is managed using the useState hook in React.

The useEffect hook is used to fetch data from the API during the initial load of the application.

In the navbar, a cart icon displays the total number of products currently in the cart.
